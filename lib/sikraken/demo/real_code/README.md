# Sikraken on real C code: four short examples

The document that describes these examples (what each one shows, how to run them, how to run the Unity tests that
Sikraken writes, and what real-code mode does not do yet) is a Google Doc, which is its only copy:
"Sikraken real-code demo" in the owner's "Sikraken Docs" folder,
https://docs.google.com/document/d/1Yt-kN8mYPt-fC3FEAvafqPnDK2QnvnZq0Kwu86mqHy0/edit (access is given by the owner).

To run all four, from the root of the checkout: `demo/real_code/run_demo.sh` (or one of them: `demo/real_code/run_demo.sh linked_list`).
